# Chrome ClientHello extension registry

Generated by `tools/extension_registry.py` - do not edit by hand.

Covers every extension id seen in the library's Chrome captures plus every id the vendored BoringSSL names. `state` says how this crate emits it:

- `native` - BoringSSL writes it with an existing API
- `patch` - needs `scripts/boringssl/chrome4832.patch`
- `cache` - needs the session cache (resumed connection)
- `unsupported` - comes from a capture but BoringSSL cannot write it
- `unknown` - known to BoringSSL but never seen in a Chrome capture
