Provider 机制端到端验证：mock 云端指纹服务（tools/cloud_api.py） + RemoteProvider 例子
========================================================================================

1) 先起 mock 云端服务（Bearer token 保护 + ETag/304 复验）：

   $ python3 tools/cloud_api.py goal-evidence/cloud-library.json --port 8747 --bearer-token demo-token
   [cloud-api] serving goal-evidence/cloud-library.json at http://127.0.0.1:8747/fingerprints.json etag="df78ef858e41cd7b" bearer=required

2) 注册云端 provider 并解析记录（examples/cloud_provider.rs）：

   $ FINGERPRINT_CLOUD_URL=http://127.0.0.1:8747/fingerprints.json \
     FINGERPRINT_CLOUD_TOKEN=demo-token target/debug/examples/cloud_provider
   cloud_premium -> target chrome150, family chrome
   cloud_chrome_full -> http3 settings 4, initial packet Some(1), boundary Some(WebKit), splits cookies true
   go1.26 -> family cloud (provider cloud-acme)
   provider builtin (priority 0, 187 records, fingerprints embedded in this crate, generated by tools/gen_fingerprints.py)
   provider cloud-acme (priority 50, 4 records, premium records from the acme fingerprint service), overrides go1.26
   after refresh, cloud_premium resolves: true
   after unregister, cloud_premium resolves: false

3) mock 服务日志——注册时首次拉取 200，refresh 带 If-None-Match 复验命中 304，库记录保留：

   [cloud-api] GET /fingerprints.json if-none-match=None authorization='Bearer ***' -> 200
   [cloud-api] GET /fingerprints.json if-none-match='"df78ef858e41cd7b"' authorization='Bearer ***' -> 304

要点：
- cloud_premium / cloud_chrome_patch 用 extends 别名复用内置 chrome150 的线上字节，只改元数据；
- cloud_chrome_full 是完整 profile 记录：TLS + HTTP/2 + headers + multipart 边界 + cookie 拆分 + HTTP/3，
  不依赖任何内置预置（initial packet 1、4 个 SETTINGS 含 GREASE、boundary WebKit、拆分 cookie）；
- go1.26 与内置同名、priority 更高（PRIORITY_CLOUD），注册期间遮蔽内置记录，unregister 后恢复；
- builtin 187 条记录（154 base + 33 aliases）始终是默认 provider，priority 0，不可卸载。
